🎮 Tic-Tac-Toe Web Application

This project is a fun and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.
Players can enjoy the classic 3x3 grid game, taking turns as X and O, trying to get three in a row — horizontally, vertically, or diagonally.
You can also add an AI opponent to make it more challenging!

🚀 Features
🎲 Two-player mode — play with a friend on the same device.
🤖 AI opponent (optional) — play against a simple computer player.
🧩 Dynamic game board built with HTML and styled with CSS.
🧠 JavaScript logic handles:
User clicks and moves
Game state tracking
Win and draw conditions
Reset functionality
📱 Responsive design — works smoothly on mobile and desktop devices.
✨ Simple, clean, and engaging user interface

🧩 Technologies Used
HTML5 → Defines the structure of the 3x3 grid and control buttons.
CSS3 → Styles the game board, highlights winners, and provides a modern look.
JavaScript (ES6) → Implements game logic such as turn tracking, win detection, and interactivity.

🧠 How It Works
The 3x3 game grid is created using HTML <div> elements.
CSS defines the layout, grid lines, and hover effects.
JavaScript:
Detects when a user clicks on a square.
Alternates between “X” and “O”.
Checks for winning combinations after every move.
Displays the winner or draw message.
Provides a Reset button to start a new game.
